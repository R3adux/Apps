Lampe hinzufügen

Der QR-Code von der Lampe oder ihrer Verpackung – oder der, den ein anderes Licht unter Teilen zeigt: dann kommen alle Lampen darin auf einmal dazu.

Ist die Lampe schon in einer anderen App (z. B. SMART+), erzeuge dort einen Code zum Teilen.

    Teilen

    Der Code wird vorbereitet – die Lampen werden zum Teilen geöffnet …

    Auf dem anderen Gerät in Licht Lampe hinzufügen → QR-Code scannen wählen und diesen Code scannen. Die Lampen müssen dort nicht neu eingerichtet werden.

    Für andere Matter-Apps (z. B. SMART+) stattdessen diese Ziffern eingeben:

    QR-Code scannen

    Halte die Kamera auf den QR-Code.
