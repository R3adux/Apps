# Overlord

Neues Projekt rund um *Overlord* (Light Novel von Kugane Maruyama, Anime von Madhouse). Was genau daraus wird, steht noch
nicht fest – zuerst kommt eine gründliche Wissensgrundlage.

**Stand: Recherche.** Es gibt noch keine App und nichts zum Herunterladen.

## Inhalt

| Ordner | Was |
|---|---|
| [`docs/recherche/`](docs/recherche/) | Alles über das Werk: Medien, Welt, Nazarick, Figuren, Handlung Band 1–16, Glossar – mit Quellen |
| [`docs/zeichenstil/`](docs/zeichenstil/) | Der Zeichenstil von Light Novel, Manga und Anime |
| [`zeiterfassung/`](zeiterfassung/) | Je Aufgabe eine kleine Datei mit Start, Ende und Dauer |

## Hinweise

- **Spoiler:** Die Recherche reicht bis Light-Novel-Band 16.
- **Rechte:** *Overlord* gehört Kugane Maruyama, so-bin und KADOKAWA. Das Repo enthält keine Bilder oder Texte aus dem Werk,
  nur eigene Beschreibungen und Zusammenfassungen.
